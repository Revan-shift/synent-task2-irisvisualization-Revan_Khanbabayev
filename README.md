# Synent Technologies - Data Science Internship
## Task 2: Data Visualization with Iris Dataset

### 📌 Project Overview
This project is part of the **Synent Technologies Data Science Internship Program**. The goal is to perform a comprehensive visual analysis of the classic **Iris Dataset** to identify patterns and relationships between different floral features.

### 📊 Dataset Information
The Iris dataset consists of 150 samples from three species of Iris flowers:
* Iris-Setosa
* Iris-Versicolor
* Iris-Virginica

Each sample has four features:
1.  Sepal Length (cm)
2.  Sepal Width (cm)
3.  Petal Length (cm)
4.  Petal Width (cm)

### 🛠️ Technologies Used
* **Python** (Core Language)
* **Pandas** (Data Manipulation)
* **Matplotlib & Seaborn** (Data Visualization)
* **Jupyter Notebook** (Development Environment)

### 🚀 Key Visualizations & Analysis
In this task, I have implemented the following visualizations:
1.  **Bar Chart:** Visualizing the frequency of each species to check for dataset balance.
2.  **Histogram:** Analyzing the distribution and density of petal lengths.
3.  **Scatter Plot:** Exploring the relationship between Sepal Length and Width, categorized by species.
4.  **Pair Plot:** A comprehensive matrix showing correlations between all numerical features.

### 💡 Key Insights
* **Species Separation:** Iris-Setosa is clearly distinguishable from the other two species based on its smaller petal size.
* **Correlation:** There is a strong positive correlation between Petal Length and Petal Width.
* **Feature Importance:** Petal measurements are more reliable than Sepal measurements for classifying the flower species.
